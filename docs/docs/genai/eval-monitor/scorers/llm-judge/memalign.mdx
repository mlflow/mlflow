# MemAlign Optimizer (Experimental)

:::warning[Experimental Feature]
MemAlign is an experimental optimizer. The API may change in future releases.
:::

**MemAlign** is an experimental optimizer that uses a dual-memory system inspired by human cognition to learn from natural language feedback. It offers significant speed and cost advantages over traditional prompt optimizers.

## Requirements

For alignment to work:

- Traces must contain human assessments (labels) with the **same name** as the judge name
- Natural language feedback (rationale) is highly recommended for better alignment
- A mix of positive and negative labels is recommended

## How MemAlign Works

MemAlign maintains two types of memory:

- **Semantic Memory**: Stores distilled guidelines extracted from feedback. When an expert explains their decision, MemAlign extracts generalizable rules like "Always evaluate safety based on intent, not just language."

- **Episodic Memory**: Holds specific examples, particularly edge cases where the judge made mistakes. These serve as concrete anchors for situations that resist easy generalization.

When evaluating new inputs, MemAlign constructs a dynamic context by gathering all principles from semantic memory and retrieving the most relevant examples from episodic memory—similar to how human judges reference both a rulebook and case history.

## Basic Usage

See [make_judge documentation](/genai/eval-monitor/scorers/llm-judge/custom-judges) for details on creating judges.

```python
import mlflow
from mlflow.genai.judges import make_judge
from mlflow.genai.judges.optimizers import MemAlignOptimizer

# Create a judge
judge = make_judge(
    name="politeness",
    instructions=(
        "Given a user question, evaluate if the chatbot's response is polite and respectful. "
        "Consider the tone, language, and context of the response.\n\n"
        "Question: {{ inputs }}\n"
        "Response: {{ outputs }}"
    ),
    feedback_value_type=bool,
    model="openai:/gpt-5-mini",
)

# Create the MemAlign optimizer
optimizer = MemAlignOptimizer(
    reflection_lm="openai:/gpt-5-mini",
)

# Retrieve traces with human feedback
all_traces = mlflow.search_traces(return_type="list")
alignment_traces = [
    trace
    for trace in all_traces
    if any(
        feedback.name == "politeness"
        for feedback in trace.info.assessments
        # feedback name must match the judge name for alignment to work
    )
]

# Align the judge
aligned_judge = judge.align(traces=alignment_traces, optimizer=optimizer)
```

## Parameters

| Parameter          | Type                | Default                                                                                            | Description                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| ------------------ | ------------------- | -------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `reflection_lm`    | `str`               | See [Supported Judge Models](/genai/eval-monitor/scorers/llm-judge/custom-judges/supported-models) | Model used for extracting guidelines from feedback. See [Supported Judge Models](/genai/eval-monitor/scorers/llm-judge/custom-judges/supported-models) section for which models are supported.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| `retrieval_k`      | `int`               | `5`                                                                                                | Number of relevant examples to retrieve from episodic memory during inference.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| `embedding_model`  | `str`               | `"openai:/text-embedding-3-small"`                                                                 | Model for episodic memory retrieval. Must be in `<provider>:/<model-name>` format.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| `retrieval_fields` | `list[str] \| None` | `None`                                                                                             | Judge fields to embed for episodic memory retrieval, drawn from `"inputs"`, `"outputs"`, `"expectations"`, and `"trace"`. Each must be referenced by the judge instructions. A `"trace"` field embeds only the root span's request and response text, so combining it with `"inputs"` or `"outputs"` mostly repeats them. Defaults to the first of inputs, outputs, expectations, conversation, or trace that the instructions reference. With multiple fields, examples are ranked by the sum of their per-field cosine similarities to the query, so the top examples are close on all chosen fields. A field an example lacks contributes 0. Each field adds one embedding index and one query embedding per scoring call. |

When you re-align an already aligned judge, leaving `retrieval_fields` unset keeps the judge's existing `retrieval_fields`. If every trace is already in memory unchanged and the retrieval fields stay the same, the judge is returned as-is with its existing parameters. Otherwise, the other parameters come from the optimizer you pass, or from the defaults above.

The number of parallel threads for LLM calls during guideline distillation can be configured via the `MLFLOW_GENAI_OPTIMIZE_MAX_WORKERS` environment variable (default: 8).

## Inspecting Learned Knowledge

After alignment, you can inspect what the judge has learned by viewing the updated instructions:

```python
# View the updated instructions with distilled guidelines
print(aligned_judge.instructions)
# Output includes appended guidelines like:
# "Distilled Guidelines (7):
#   - Responses must be factually accurate...
#   - Use neutral, descriptive language..."
```

## Correcting What the Judge Learned

MemAlign offers two ways to correct an aligned judge. Choose based on whether the problem is a distilled rule or the feedback itself:

| Situation                                                                                               | Method                       | Effect on the returned judge                                                                                                                                                               |
| ------------------------------------------------------------------------------------------------------- | ---------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| The feedback examples are still useful, but a distilled rule is incorrect, too broad, or contradictory. | `remove_guidelines(indices)` | Removes exactly the selected rules. Keeps all episodic examples available for retrieval, and preserves the remaining guidelines' source-trace mappings.                                    |
| Particular traces contain incorrect or outdated feedback that should no longer be used as examples.     | `unalign(traces)`            | Removes those traces' examples from episodic memory. Drops a guideline when all of its recorded source traces are included in the removal; guidelines shared with other traces can remain. |

For example, correctly labeled polite replies might produce an overly broad rule such as "Every polite reply must start with Hello". Use `remove_guidelines()` to drop that rule while keeping the useful examples. If a rude reply was incorrectly labeled polite, use `unalign()` to remove that trace's examples instead. If an unwanted guideline survives because it also has other source traces, remove that guideline explicitly too.

Both methods return a judge, so use the returned judge (and register it if you want to keep the change). Neither method deletes the stored MLflow traces or their assessments; they only change what the judge keeps in memory.

## Removing Specific Guidelines

To list the learned guidelines, use `guidelines`. To drop specific ones (for example, contradictory guidelines), pass their 0-based positions to `remove_guidelines`. It returns a new judge and leaves the original unchanged. Examples, MemAlign settings (reflection model, retrieval size, and embedding model), and scorer settings such as `timeout` and `aggregations` are kept.

```python
for i, guideline in enumerate(aligned_judge.guidelines):
    print(i, guideline)

cleaned_judge = aligned_judge.remove_guidelines([3, 17])
cleaned_judge.register()
```

Indices refer to the current list, so call `guidelines` again on the new judge before removing more. A later `align` can distill a removed guideline again (for example, after feedback on one of its source traces changes), so check `guidelines` after each alignment.

## Removing Feedback (Unalignment)

If requirements change or feedback was incorrect, you can remove the feedback from specific traces:

```python
import mlflow

# Retrieve traces with outdated or incorrect feedback
traces_to_forget: list[mlflow.entities.Trace] = mlflow.search_traces(
    filter_string="tag.outdated = 'true'",
    return_type="list",
)

# Remove those traces' examples, plus any guideline whose source traces are all in this list
updated_judge = aligned_judge.unalign(traces=traces_to_forget)
```
